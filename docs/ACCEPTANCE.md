## 本轮修复

- 同段重复摘录保存选中位置，引用链接带 Unicode 码点；模型摘录有歧义时拒绝保存。
- 搜索返回保留说话人、日期、未知日期选项与分页，防止迟到请求覆盖新结果。
- 文件上传严格按 UTF-8 解码，坏编码明确拒绝并允许其他文件继续处理。
- 模型输出文本和回答结构严格校验，认证、限流、空响应、超时和坏结构都有故障用例。
- 显式空选或失效资料不回退成全库；选部分来源时卡片也按来源限制。
- 模型预览绑定问题、资料版本、角色、卡片、目标地址与模型名，改变后不能沿用旧预览。
- AI 不能把没有人工审核卡片依据的要点标为已确认历史决定；AI 原话不能直接建立用户决定。
- 已确认卡片仅保存修改时也执行事实正文与引用规则。
- 导入预览不能跨资料库确认；关键输入结构经过验证，HTTP 请求有读取大小上限。
- 模型输入预算包含结构与问题，保留服务代理路径，拒绝 URL 内凭据，预先取消不会仍发送。
- 恢复先构建及校验新库、做一致性快照，再原子替换；坏包和损坏引用不替换原库。
- 删除后迟到提炼不写回；旧交接预览不能因晚保存而重新进入应用和备份。
- 交接目标或卡片选择变化后，旧正文不能直接导出；主题异步加载避免旧结果覆盖。
- 启停统一实例身份校验，拒绝 PID 路径前缀碰撞；自定义数据目录与 PID 文件一致。
- 性能脚本使用新临时库、正确记录运行系统；浏览器测试不删除固定目录。
- 依赖已按安全公告升级；当前 npm 审计 0 项已知漏洞。
