# 1.0.0-beta.1

First public source release of Xushang: a single-user, local Chinese app for recovering original chat context, reviewing decisions and preparing editable handoffs.

The release includes the rebuilt component-based interface, separated server routes, no-model workflows and regressions for deletion, backup, role correction, historical citations, scope preview, model limits and instance ownership. Additional release review closes empty-scope expansion, unrelated-card sends, stale previews, unsafe restore replacement and PID-prefix collisions.

Only source, tests, synthetic fixtures and documentation are published with fresh Git history. No personal library, model credential, runtime log or previous private commit history is included. MIT license.

Validation and limits are recorded in [ACCEPTANCE.md](ACCEPTANCE.md). Real-provider content quality and usefulness on private chats remain unverified. This release does not expose the local application as a public service.
