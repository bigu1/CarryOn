# 原始首版验收要求

这些是要求，不能当作当前通过证据；当前证据见 ../ACCEPTANCE.md。真实模型与真实使用必须单独报告。

## 2. 本地核心验收矩阵

以下 C01–C30 全部属于首版必做。可以合并测试实现，但不能删除行为要求。

| ID | 场景与操作 | 通过条件 | 至少提供的证据 |
| --- | --- | --- | --- |
| C01 | 新环境按说明安装并打开 | 支持环境与版本写清；不依赖执行者未说明的全局包 | 干净副本安装/构建日志和版本记录 |
| C02 | 不配置模型首次进入 | 演示与真实资料入口可用；需要模型的功能说明原因 | 浏览器截图和实际操作 |
| C03 | 粘贴、TXT、Markdown、自有 JSON 导入 | 四种入口真实入库；预览可取消不入库 | 集成测试及至少一种浏览器导入 |
| C04 | 不明确角色和日期 | unknown 保留；导入时间不冒充来源时间；可校正 | 合成案例、库记录、页面 |
| C05 | 代码块/引用中的角色标签 | 不错误拆分；无法可靠识别时按整段导入 | 针对性测试和预览 |
| C06 | 同内容改文件名再次导入 | 不制造重复资料/卡片；来源信息有明确处理 | 计数前后与去重测试 |
| C07 | 相同 externalId 的内容更新 | 显示修订；原版本和相关引用不会悄悄漂移 | 修订测试和来源跳转 |
| C08 | 文件超限、空文件、乱码、坏 JSON、未知版本 | 正确拒绝/提示；无半份资料；可重试 | 输入样例和集成记录 |
| C09 | 中文短词与长词检索 | 1/2 汉字、中文词组均能命中；英文/数字也可用 | 已知答案查询集 |
| C10 | 引号、百分号、下划线、代码片段查询 | 无注入/崩溃；按定义的字面匹配 | 参数化与回归测试 |
| C11 | 主题、角色、日期筛选和分页 | 范围正确、排序稳定、无重复漏页；unknown 日期可查 | 集成和浏览器证据 |
| C12 | 中文/emoji/重复句子的引用 | 精确跳到原文位置；可读前后文；返回位置保留 | 边界测试与浏览器录像或截图序列 |
| C13 | 人工建立/修改卡片 | 保存后重启仍在；引用与用户备注区别清晰 | 端到端记录 |
| C14 | 待审核、确认、拒绝 | 不自动批量确认；拒绝记录不混入已确认结论 | 状态测试和界面 |
| C15 | 同主题旧决定和新决定 | 保留历史；用户确认后才建立替代；可以纠正 | 变更/撤销流程测试 |
| C16 | 时间不明或跨主题内容冲突 | 不凭导入顺序推断最新；不跨主题覆盖 | 种子场景与回归 |
| C17 | 模板交接 | 无模型也能生成；目标、决定、尝试、问题、限制、来源齐全 | 两份实际生成的合成交接 |
| C18 | 交接编辑/复制/下载 | 输出与预览一致；未审核候选须显式加入并标注 | 浏览器复制结果和下载文件 |
| C19 | 超过交接长度目标 | 提示未包含项；不静默删限制和冲突 | 长主题实际操作 |
| C20 | 删除带派生内容的资料 | 原文、索引、卡片正文、已存回答/交接均处理；UI 不能再取回 | 数据/API/UI 三层查询 |
| C21 | 删除/修订时分析仍在运行 | 迟到响应被丢弃或明确失效；不复活旧内容 | 可控制延迟的模拟服务测试 |
| C22 | 备份恢复到空库 | 资料、卡片、关系、引用一致；凭据不在备份内 | 一次真实恢复演练和校验摘要 |
| C23 | 备份损坏或版本不兼容 | 拒绝且原库不变；有可理解错误 | 恢复失败前后哈希/内容证明 |
| C24 | 服务停止再启动 | 用户数据完整；演示重置不动个人库 | 重启和两库隔离证据 |
| C25 | 一步启动/停止、端口冲突、中文含空格路径 | 能打开正确页面；不结束其他进程；说明不要求用户记命令 | 本机真实执行记录 |
| C26 | 跨源写请求与错误 Host | 按既定本机保护方案拒绝；合法本机操作正常 | HTTP 防护测试 |
| C27 | 恶意 HTML、脚本、远程图片、文件名穿越 | 不执行/不联网加载/不越界写入 | 浏览器与文件边界测试 |
| C28 | 无模型的正常业务流程 | 无对外业务流量、遥测、远程字体或 CDN 依赖 | 浏览器网络记录及服务代码核对 |
| C29 | 多视口与键盘 | 1440×900、1024×768、390×844；主流程无溢出，焦点和错误可见 | 实际渲染截图与键盘检查记录 |
| C30 | 部分导入成功与任务失败/取消 | 结果逐份可见；不假成功；重试幂等；取消不会继续写入 | 故障注入及浏览器状态 |

## 3. AI 验收矩阵

AI 功能代码和模拟故障路径必须实现；真实服务未授权或不可用时，A01–A04 可以先验证，A05–A10 必须保留 BLOCKED / NOT_RUN，不能宣布 AI 全部完成。

| ID | 验收内容 | 通过条件与证据 |
| --- | --- | --- |
| A01 | 接入与凭据 | 服务端调用；凭据不落浏览器、数据库、日志、Git、导出；重启失效有说明 |
| A02 | 发送范围与请求边界 | 用户选定材料可见；请求内容不夹带别的主题；未确认不发送；目标不能被资料重写 |
| A03 | 协议失败与预算 | 认证失败、超时、限流、空响应、坏结构、过大响应、重定向均可控；重试有上限 |
| A04 | 输出校验与任务幂等 | 不存在/越范围/错位置引用不能入库；重试不重复；删除竞态通过 |
| A05 | 真实提炼 | 用户授权服务上实际产生候选；所有事实候选可追溯；角色/否定/条件/引用场景无关键误报 |
| A06 | 真实自然语言回答 | 至少 5 个不同问题；答案逐条有支持；找不到证据会承认不足 |
| A07 | 真实冲突与时间 | 不能把晚导入当晚发生；冲突并列；最新只相对于已导入资料 |
| A08 | 真实长资料/部分失败 | 覆盖范围和失败段可见；没有静默截断或宣称全覆盖 |
| A09 | 真实交接润色 | 至少 2 份；限制、冲突、未核验状态保留；未产生新事实/新权限 |
| A10 | 记录实测条件 | 服务名称、模型返回标识、提示模板版本、日期、输入集、调用次数、实测用量及未知费用都可追溯；无密钥 |

真实测试优先使用合成材料，必须先获得用户对服务、材料和调用预算的授权。即使已有 Key，也不代表允许无限探测。不要为本项目自动切换用户全局模型或复用其他项目账号。
