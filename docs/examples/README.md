# 合成交接生成样例

两份文件由隔离合成库实际调用 `/api/handoffs/preview` 生成，采用不同目标与 short/full 模板。不是私人聊天，也不是用户认可真实工作价值的证据。

- [短版：继续核对合成乙方案](handoff-short.md)
- [完整版：把合成材料交给下一位 AI](handoff-full.md)

来源日期明确为未知；旧决定仍作历史保留；约束、尝试、未解决问题和用户备注均保留。合成原文用于进程重启演练，内容如下：

```text
用户：先采用合成甲方案，资料只留在本机。
助手：可以考虑云同步。
用户：试过甲方案，读取方式太繁琐。现在改用合成乙方案，替代甲。下一步如何核对变化？不要发送真实聊天。
```
